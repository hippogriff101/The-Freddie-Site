# The-Freddie-Site

After buying this domain in November 2025 with a [Summer of Making](https://summer.hackclub.com) Grant I'm finally making a proper, well made site. 

~This is Version Three, submitted to [Macondo](https://macondo.hackclub.com/)~

We are now on Version Four, same site with FLASK!

## Running locally

The site is a [Flask](https://flask.palletsprojects.com/) app.

```
pip install -r requirements.txt
python app.py
```

Pages live in `templates/` (they all extend `base.html`), and CSS, JS and images live in `static/`.
